Counts in the combined log: 17× HTTP 200, 1× 404 (duplicate register, expected), 1× 208 (wrong password, expected), 1× 403 (unauthenticated review, expected).

One fix was needed during the build: the first test run failed at startup with `Error: Cannot find module './booksdb.js'` because `router/general.js` and `router/auth_users.js` used `./booksdb.js`; corrected to `../booksdb.js` (the file lives at the project root). After that fix, `node --check` passed on all four JS files and the full run above passed.

Notes / limits (verified, not assumed):
- Users and reviews are in-memory only: they reset when the server restarts. The test user `jarif` / `password123` exists only in that test run's server process.
- Review add/modify accepts both the IBM lab query form (`?review=...`) and a JSON body (`{"review": "..."}`).
- JWT/session secrets are the IBM lab defaults (`access` / `fingerprint_customer`); this is a coursework app, not production-hardened.
